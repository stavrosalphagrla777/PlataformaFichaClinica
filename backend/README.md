# Plataforma Digital de Ficha Clínica TP - Backend

Backend Laravel con MySQL y control de acceso por roles para estudiantes de 3.º y 4.º medio, docentes y administradores.

La guía de instalación y las verificaciones actuales están en el [README principal](../README.md) y en [Estado de implementación y pruebas](../docs/ESTADO_DE_IMPLEMENTACION_Y_PRUEBAS_19-11-2026.md).

No usar pacientes ni datos de salud reales: este sistema corresponde al Hospital de Simulación Virtual del liceo. El entorno productivo requiere autenticación segura, certificados HTTPS, respaldos y validación institucional.
